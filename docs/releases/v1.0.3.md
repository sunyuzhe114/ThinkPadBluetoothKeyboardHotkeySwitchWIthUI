# 1.0.3：自适应窗口与蓝牙热键修复

## 下载

下载 Assets 中的 **ThinkPadKeyboardSwitcher.exe**，放到固定目录后双击运行。
这是 Windows x64 自包含版本，无需另外安装 .NET。`SHA256SUMS.txt` 提供文件校验值。
程序未进行数字签名，请确认下载来源并遵守设备安全策略。

## 更新

- 最大化或调整窗口尺寸时，按键列表随可用空间扩展、列宽自动适配。
- 修正从大窗口还原后原生列宽刷新时序，避免多余的横向滚动条。
- 状态提示自动换行，底部操作按钮始终可见。
- 收起到托盘后重新打开，保留最大化状态。
- 包含蓝牙 F1 修复：系统合成的已知多媒体热键正确转换为 F 键，自身输出不重复映射；实体键盘 F1 已确认不再静音。
- 保留当前用户登录启动、模式记忆和手动开启的限时 F1 诊断。

## 升级与验证

先从托盘菜单“退出”，再替换原 EXE 并运行。保留原路径时，无需重新设置登录启动项。
改变路径时，请在新位置重新勾选“登录后自动启动”。
构建执行 130 项映射/诊断断言、40 项 Windows 原生布局断言和监听安装/卸载自检。
目前验证环境为 Windows 11 x64；全局映射会影响所有键盘，F12 不改变。
不同型号以及 F10/F11 仍需分别验证。使用与来源说明见仓库 README 和 THIRD-PARTY.md。
