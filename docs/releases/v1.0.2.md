# 1.0.2：窗口自适应与蓝牙 F1 修复

## 下载与运行

下载本页 Assets 中的 **ThinkPadKeyboardSwitcher.exe**，放到固定目录后直接运行。
这是 Windows x64 自包含版本，无需另外安装 .NET；目前在 Windows 11 x64 上验证。
`SHA256SUMS.txt` 提供文件校验值。程序尚未进行数字签名，请确认下载来源和文件校验值，遵守设备的安全策略。

## 更新内容

- 最大化和调整窗口大小时，按键列表随可用空间扩展，列宽自动适配。
- 状态提示和选项按内容排版，长提示自动换行，操作按钮保持在底部。
- 收起到托盘后重新打开，保留之前的最大化状态。
- 包含 1.0.1 的蓝牙热键修复：允许系统合成的静音、音量等已知热键转换为 F 键，同时跳过自身输出以避免循环。实体键盘 F1 已验证不再静音。
- 提供手动启用、两分钟自动结束的 F1 诊断，不记录文字输入。

## 升级

从托盘菜单选择“退出”，用新 EXE 替换原文件，再启动。
保留原路径时，现有登录启动项和个人模式设置无需重新配置。
如果改变程序位置，请在新位置重新勾选“登录后自动启动”。

## 验证与限制

构建包含 130 项映射/诊断断言、39 项 Windows 布局断言以及原生监听安装/卸载自检。
映射对所有键盘生效，并不切换蓝牙配对对象；F12 保持原样。
不同键盘型号、F10/F11 组合键以及管理员窗口仍需按实际环境验证。
完整使用、开发与来源说明见仓库 README、docs/DEVELOPMENT.md 和 THIRD-PARTY.md。
